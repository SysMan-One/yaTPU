==============================================================================
TPU KEY REFERENCE  --  physical PC/xterm keys -> TPU commands
generated from tpu.c: s_defkeys[] / s_keydef_defaults()
==============================================================================

TPU speaks VT220/EDT: GOLD, PF1-PF4, KP0-KP9.  Ordinary keyboards are not
labelled that way, so this sheet lays the bindings out on the keys that
actually send those codes -- same physical position as on your keyboard.

Legend:  plain command   GOLD command (press PF1 / F1, keypad - or Esc first, then the key)

PC KEYPAD IN AN EMULATOR WITHOUT APPLICATION MODE  (most of them)
NumLock off: the digits are the cursor block, 5 is "Begin", / * - + are
text, Enter is Return. NumLock on: plain digits. GOLD is Esc here.
------------------------------------------------------------------------------

------------------------------------------------------------------------------
VT220 EXTRAS (F13-F20) -- no key on a PC keyboard, same action reachable via:
------------------------------------------------------------------------------

  F13 (ERASE WORD)     = Ctrl-J
  F14 (CHANGE MODE)    = Ctrl-A
  F15 "Help"           = PF2, GOLD-H
  F16 "Do"             = PF4, keypad 7
  F17 (SHOW BUFFERS)   = GOLD-S
  F20 (OTHER WINDOW)   = GOLD-O

------------------------------------------------------------------------------
NOTES
------------------------------------------------------------------------------
* Home/End quirk: most xterms send the codes above, but some terminals
  (Linux console among them) send Home/End as the VT220 Find/Select codes
  instead. If Home/End do not move the cursor, use Ctrl-H / Ctrl-E, or
  GOLD-F for Find.
* This sheet is a snapshot of the default bindings. Press GOLD-K (or
  GOLD-F2, or type SHOW KEYS after DO) inside TPU for the live table,
  including anything redefined with GOLD-D / DEFINE KEY.
