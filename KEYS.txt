==============================================================================
TPU KEY REFERENCE  --  physical PC/xterm keys -> TPU commands
generated from tpu.c: s_defkeys[] / s_keydef_defaults()
==============================================================================

TPU speaks EDT/EVE: GOLD, a keypad, KP0-KP9.  The keypad is laid out the way
EDT emulators put the VT keypad on a PC: the VT's PF row sits on NumLock / * -,
here moved one key off NumLock (a terminal never sends NumLock), and HELP is F1.
This sheet lays the bindings out on the keys that actually send those codes.

Legend:  plain command   GOLD command (press keypad / or Esc first, then the key)

------------------------------------------------------------------------------
FUNCTION ROW  (only F1 is bound; F1 sends the same code as the VT's PF1)
------------------------------------------------------------------------------

+-------------+-------------+-------------+-------------+-------------+-------------+
|      F1     |      F2     |      F3     |      F4     |      F5     |      F6     |
|     HELP    |      --     |      --     |      --     |      --     |      --     |
|GOLD:SHOW KEY|             |             |             |             |             |
+-------------+-------------+-------------+-------------+-------------+-------------+

F2-F12 have no default binding: free for DEFINE KEY (GOLD-D) or a key file.

------------------------------------------------------------------------------
NO DEFAULT BINDING  -- F2-F20, Help, Do (VT220 keys); the actions are on:
------------------------------------------------------------------------------

  ERASE WORD           = Ctrl-J
  CHANGE MODE          = Ctrl-A
  HELP                 = F1, GOLD-H
  DO                   = keypad -, keypad 7, GOLD-Enter
  SHOW BUFFERS         = GOLD-S, GOLD-keypad 7
  OTHER WINDOW         = GOLD-O
  EXIT / QUIT          = Ctrl-Z, GOLD-X / GOLD-Q

------------------------------------------------------------------------------
NOTES
------------------------------------------------------------------------------
* Home/End quirk: most xterms send the codes above, but some terminals
  (Linux console among them) send Home/End as the VT220 Find/Select codes
  instead. If Home/End do not move the cursor, use Ctrl-H / Ctrl-E, or
  GOLD-F for Find.
* An emulator that maps NumLock to PF1 itself (Tera Term and the like)
  sends the code of F1 for NumLock, so there NumLock is HELP, not GOLD.
* This sheet is a snapshot of the default bindings. Press GOLD-K (or
  GOLD-F1, or type SHOW KEYS after DO) inside TPU for the live table,
  including anything redefined with GOLD-D / DEFINE KEY.
